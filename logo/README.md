# Logo client

## Fundal închis (Noir / onyx)

```
logo/logo.png
```

Logo alb sau deschis, PNG transparent.

## Fundal deschis (Sage, Nisip) — opțional, recomandat

```
logo/logo-dark.png
```

Variantă închisă / colorată pentru header deschis. Dacă lipsește, aplicația colorează automat `logo.png` pe Sage și Nisip.

Copiere în `public/logo/` nu e obligatorie — se citește din `logo/`.
